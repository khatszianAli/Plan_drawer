# Plan Drawer v3.11 — Structured Edition

Конструктор плана дома разбит по зонам ответственности. Сборщик и установка зависимостей не требуются.

## Запуск

Откройте `index.html` двойным кликом. Проект использует обычные `defer`-скрипты, поэтому работает через `file://`.

Можно также запустить локальный сервер:

```bash
python3 -m http.server 8000
```

После этого откройте `http://localhost:8000`.

## Основные правила геометрии

- Толщина каждой стены фиксирована: **150 мм**.
- Стены рассчитываются как физические прямоугольники, а не как визуальные линии.
- Первая вручную построенная обычная стена или стена веранды начинается с **(0, 0)**.
- Начало координат находится слева сверху; положительное направление оси **Y идёт вниз**.
- Перемещение остаётся свободным, но поддерживает направляющие и магнитную привязку к физическим граням.
- Зазор до **100 мм** у конца стены автоматически закрывается при завершении построения или редактирования.
- Подложку можно совместить левым верхним углом с **(0, 0)** и отразить по горизонтали или вертикали.

## Важное правило порядка JS

Файлы подключены как обычные скрипты, чтобы сохранить запуск через `file://`. Поэтому порядок тегов `<script defer>` в `index.html` является частью архитектуры. `bootstrap.js` должен оставаться последним.
