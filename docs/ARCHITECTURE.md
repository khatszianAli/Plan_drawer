# Архитектура проекта

## Почему не используются ES Modules

При прямом открытии `index.html` через `file://` браузеры, особенно Safari, могут блокировать загрузку локальных ES Modules из-за CORS. Поэтому проект разделён на обычные deferred scripts. Это сохраняет простоту запуска без Node.js и сервера.

## Поток приложения

1. `core/runtime.js` создаёт общие ссылки на DOM, константы и состояние.
2. Геометрические файлы определяют физические границы стен и алгоритмы привязки.
3. Editor-файлы реализуют инструменты: рисование, фигуры, ластик, выбор, перемещение и историю.
4. Canvas-файлы отвечают за систему координат, масштаб и отрисовку.
5. Feature-файлы реализуют подложку, JSON и автосохранение.
6. `app/events.js` связывает DOM, клавиатуру и Canvas с функциями редактора.
7. `app/bootstrap.js` восстанавливает состояние и запускает первый render.

## Где вносить изменения

| Задача                      | Файл                                                          |
| --------------------------- | ------------------------------------------------------------- |
| Изменить толщину стены      | `assets/js/core/runtime.js`, константа `FIXED_WALL_THICKNESS` |
| Изменить физические границы | `assets/js/geometry/wall-geometry.js`                         |
| Изменить магнитную привязку | `assets/js/geometry/snapping.js`                              |
| Изменить перемещение        | `assets/js/editor/selection.js`                               |
| Изменить рисование          | `assets/js/editor/drawing.js`                                 |
| Изменить проверку плана     | `assets/js/editor/validation.js`                              |
| Изменить визуал Canvas      | `assets/js/canvas/renderer.js`                                |
| Добавить кнопку             | `index.html` + карта `actions` в `assets/js/app/events.js`    |
| Изменить дизайн             | соответствующий файл в `assets/css/`                          |

## Состояние

Общее состояние хранится в глобальной lexical environment обычных script-файлов. Такой подход выбран осознанно ради совместимости с `file://`. Не объявляйте повторно существующие `let`/`const` имена в других файлах.

## Декларативные действия HTML

В HTML больше нет встроенных `onclick`. Кнопки используют:

- `data-mode="draw-normal"` для переключения режима;
- `data-action="export-json"` для команды;
- дополнительные `data-factor` и `data-value` для параметров.

Все команды зарегистрированы в `bindUiActions()`.
